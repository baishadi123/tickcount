# TickCount

[![Build](https://github.com/ZZPBY/tickcount/actions/workflows/android.yml/badge.svg)](https://github.com/ZZPBY/tickcount/actions/workflows/android.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

一个极简、纯离线的安卓倒数日日历。在日历上点一天、起个名字，就能看到离那一天还有多久，
或者已经过去了多久。

## 功能

- **六个页面** —— 留莹（倒数日）、作陪（心愿）、敬心（时光胶囊）、万疆（足迹）、
  日历、行舟（星图）；提醒、外观、小组件、数据等收进「设置」。
- **留莹** —— 一条一张卡片：左边超大天数，右边名称与日期；已过去的收在下面，
  置顶恒在最前，按日期或添加时间排序。
- **作陪** —— 想一起做的事，做完点勾收进「已完成」，可撤销。
- **敬心** —— 写下想说的话、选照片、录一段声音，封存到某一天，到期才能拆信；
  信笺自动分页，到期当天到点提醒。
- **万疆** —— 到过的地方：照片 / 动图 / 视频，可带上此刻的位置，按地方分组全屏翻看；
  也可切到**地图**——全部足迹化作钉，按年份点亮走过的路线，还可在图上直接选点。
- **行舟** —— 全部日子排成夜空星座，彗星沿星座航行，抵达已到来的日子便点亮它。
- **日历** —— 手写月历：倒数日彩点、胶囊 / 心愿 / 纪念日各有记号；任意一天可设为
  纪念日，在一起第 100 / 365 / 520 / 999 / 1314 天自动标出；点开某天列当天全部事件。
- **编辑与详情** —— 精确到分钟，标签不限个数；详情按年月日时分秒完整拆分，不满一天
  改为大字时分秒；可关联 16 张照片与背景图——照片引用相册原图，不占双份。
- **桌面小组件** —— 「单个」时分秒实时跳动，「清单」列出接下来的几条，都不需要权限。
- **提醒** —— 全局与单条提前量，胶囊到期同样提醒；非精确闹钟，重启自动恢复。
- **农历与双语** —— 1900–2100 按农历选日子，每年重复可选公历或农历；六套主题 +
  自定义色相，中英可切。
- **备份与恢复** —— 全部数据导出 / 导入，可选 AES-256-GCM 加密，覆盖或合并；
  另有 .ics 导出给系统日历。
- **除地图瓦片外不联网、无统计。** 运行库仅 AndroidX、Compose 与 osmdroid（地图）；
  权限只在用到时才申请。

## 一键添加多个

新建时打开「一键添加多个」，填**间隔天数**（1～3650）与**个数**（1～100）：选中的日期
本身也添加，之后每条多间隔那么多天——14 日新建、间隔 2、个数 3，得 14、16、18、20 日
共 4 条。同一批之后各自编辑或删除，互不影响。

## 倒计时的读法

目标是**所选日期当地时间的 00:00**（指定了时刻就按那个时刻算）；时刻一过，同一套算法
反向运行，标签从「还有」变成「已过去」。未开始计数的字段用短横线占位：

| 剩余时间 | 显示 |
|---|---|
| 4 个月 11 天 6 时 30 分 15 秒 | `----年04月11日 06时30分15秒` |
| 2 天 30 秒 | `----年--月02日 00时00分30秒` |
| 3 年 4 个月 11 天 6 时 30 分 15 秒 | `0003年04月11日 06时30分15秒` |

年、月、天按日历算，时、分、秒按流逝时间算，夏令时切换的那天仍算一整天。

## 桌面小组件

长按桌面空白处添加，两个可选：**单个**——默认 4×2，拖大拖小自动换排版，天数拆成
「1年1个月4天」，点击直达该条；**清单**——接下来的几条从近到远，点哪行开哪行。
面板浅色 / 深色 / 跟随系统与清单字号在侧边栏「桌面小组件」里选。

## 编译

需要 JDK 17、Android SDK Platform 37 与 Build Tools 36.0.0，`local.properties`
写好 SDK 路径（或导出 `ANDROID_HOME`）：

```bash
./gradlew testDebugUnitTest   # 单元测试
./gradlew assembleRelease     # APK -> app/build/outputs/apk/release/
```

Windows 下使用 `gradlew.bat`。

| | |
|---|---|
| 语言 / UI | Kotlin 2.4.20 · Jetpack Compose + Material 3 |
| 构建 | AGP 9.4.1、Gradle 9.6.0，版本集中在 `gradle/libs.versions.toml` |
| SDK | compileSdk 37、targetSdk 36、minSdk 27（无需 desugaring 与兼容垫片） |
| 存储 | 事件与心愿在 `SharedPreferences`；胶囊与足迹按年份存于应用私有目录 |
| 依赖 | 运行时为 AndroidX、Compose 与 osmdroid（万疆地图，图块取自高德栅格服务） |

## 隐私

全部数据只存应用私有目录；照片默认不拷贝——记录只存相册图片的 SHA-256 指纹，
显示直读相册原图，相册始终是唯一原件（旧版拷入的副本照常可用）。权限按需申请——
提醒的通知与开机自启、万疆的精确位置、相册读取（显示引用的照片或「相册体检」时才要）。
地图是唯一联网的地方：向高德请求瓦片并缓存在应用私有缓存目录，除此之外没有任何联网
与上传；备份导到哪、加不加密由你定。数据仅当 Android 自身云备份开启时才会离开设备。
